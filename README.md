# Suray AIO v2

## Requisitos

- Node.js instalado
- npm instalado

## Instalación

Instalar las dependencias del proyecto:

```
npm install
```

## Ejecutar en modo desarrollo

```
npm run dev
```

Esto inicia el servidor de desarrollo de Vite. La URL quedará disponible en la terminal.

## Compilar para producción

```
npm run build
```

## Previsualizar el build de producción

```
npm run preview
```
